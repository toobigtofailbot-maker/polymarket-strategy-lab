# polymarket-strategy-lab

`polymarket-strategy-lab` is a repo-first Polymarket and Kalshi strategy lab. The project is intended to establish deterministic governance, due diligence, safety gates, and work-package discipline before any trading functionality is built.

Current phase: WP1 - Repo-Truth Governance Foundation.

No trading functionality exists yet. No Polymarket or Kalshi API integration exists yet. Live trading is disabled by default and no strategy is authorized for live execution.

Authoritative repo-truth documentation starts at `docs/repo_truth_index.md`. Codex execution rules are in `AGENTS.md`.
