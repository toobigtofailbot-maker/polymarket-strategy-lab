# 02 — Nine real, on-demand specialists + one bounded coordinator

**Scope:** exactly A1–A9, coordinator not A10. These are target interfaces, not claims of working agents. Native repo baseline `1c981838c2cc3ff2fcd5991aa97cf78194a10a2f`; pinned Hermes `345cd2b057a452236de401d3534b8502a7465e8d`. All technical provider/venue scenarios below use frozen, already-held source bytes, fake model/provider transports or a separately authorized non-discovery technical witness. No fresh market discovery/qualification data, no profitability trials.

## Shared task, evidence and permission boundary (one coordinator)

**Proposed minimal `ResearchTask` envelope** (adapt, don't duplicate native canonical schema): `task_id` (idempotent hash of exact campaign/input/role/policy), `role_id` A1..A9, `parent_run_id`, `predecessor_task_ids`, `candidate_id?`, `hypothesis_family_id?`, native market/condition/token IDs, `source_manifest_ids`, `rule_snapshot_id?`, `source_cutoff_utc`, `blind_context_digest`, `task_reason`, `tool_policy_id`, `model_route_version`, `output_schema_version`, `deadline_monotonic`, `max_attempts`, `budget_envelope_id`, `origin_class`. Canonical market/source/Alpha IDs are **looked up**, never minted from model text. An A4 task receives the same source evidence and question as A3 but cannot read A3's answer before first-pass commit. Task record identity includes source and policy hashes, so replay cannot make newer bytes look pre-cutoff.

**Proposed `SpecialistResult`**: exact task/role IDs; host-owned child run identity (when Hermes-invoked), input and output SHA-256, source/quote/cutoff validation, `actual_effective_tool_names` from trusted registry (if observed; else `UNKNOWN`), provider/model binding and usage (if witnessed; else unknown), terminal reason, allowed one-of execution classes (`ENGINEERING_VERIFIED_OFFLINE`, `PROVIDER_WITNESSED_RUNTIME_PROVEN`, `UNVERIFIED`), successor native consumer record ID/head, elapsed monotonic, attempt cost/count and refusal/skip reasons. This is **not** a self-issued trade authorization and does not mutate native strategy versions.

**Coordinator** uses existing `hermes_controlled_runtime`/`context_broker`/Alpha registry plus the smallest durable task-intent/attempt overlay required for replay (existing store chosen at pre-draft), with closed states `PLANNED → ADMITTED → RUNNING → COMPLETED_CONSUMED` or `SKIPPED / REFUSED / FAILED / TIMED_OUT_UNKNOWN_QUARANTINED`. Persist intent *before* dispatch. On uncertainty, quarantine an in-flight run, reconcile trusted host events and **do not auto-retry** a possibly billed task. A result without verified native consumer remains `COMPLETED_UNCONSUMED` and does not count as accepted. Publish counts for all planned/admitted/skipped/refused/attempted/completed/failed/unknown/consumed without denominator shrinkage; reconcile exact parent/child/session/source IDs and append-only heads. Fairness: per-campaign/role quotas, no starvation of incident tasks, finite bounded priority queue, explicit cancellation and finite close. Restart reads prior task ledger; no phantom child or duplicate Alpha append.

**Permission isolation:** native coordinator can *route research tasks* but cannot edit canonical evidence or qualify a strategy on its own. A genuine Hermes parent may have only tools `web_search`, `web_extract`, `delegate_task` in its separately opt-in controlled profile; leaf children at most `web_search`, `web_extract`. Real captured market source rights are independently granted and strictly scoped; offline tests forbid sockets. For the pinned upstream tool resolver, specifically test `_expand_parent_toolsets`, `_resolve_child_toolsets`, `DELEGATE_BLOCKED_TOOLS`, MCP inherit=true attempts, `orchestrator_enabled=true` attempts and composite `hermes-cli`, `coding`, `safe` toolsets. Lock `max_spawn_depth=1`, `max_concurrent_children=2` for the first vertical; deny all terminal, file write, process, code execution, browser control, unrestricted HTTP/MCP, cron, memory mutation and trade/account/signer tools. Pinned `-z` sets YOLO and accepts hooks, so **actual effective loaded tools** are the security proof, not child prompt. No silently active Firecrawl/other network in offline engineering.

**Provider routing:** native deterministic first. A1/A5/A6/A7/A8 use no model for deterministic coverage, constraints, wallet delay, math or scoring. A2 receives model work only when cited source synthesis adds value. A3/A4 get independent bounded providers on targeted questions, with model version and provider identity recorded; a second call to the same model is a separate process, **not model diversity**. A9 only reasons over sanitized technical evidence and produces suggestions. All real provider plans specify hard cost/latency/request caps, no provider fallback, actual unknown pricing marked unknown and owner permission before session.

## Per-role contract and measured acceptance

### A1 — Market Scout
- **Trigger:** approved fixed universe refresh, source/census validity change, category coverage gap (after owner unlock for *real new-market discovery*). **Native work:** `alpha_discovery.py` triage and `market_catalog.py` plus `official_sdk_search_bridge.py`; local `pmxt_v2.py` not a live PMXT adapter. **Input:** native market/event/CTF IDs, source manifest and snapshot time, exact inclusion/exclusion policy. **Tools/model:** deterministic by default; only owner-permitted official SDK/public/provider reads at future technical gate; no LLM required for basic count/classification.
- **Output:** `MarketScoutCoverageReceipt` with total eligible/filtered/refused/duplicate/unknown denominator, canonical ID refs, source age, routes to A2/A5/A6/A7. **Consumer:** existing `alpha_discovery` queue/`AlphaFactory` candidate association; no new real candidates during Stages A/B. **Failure:** stale/no book, unknown market protocol, duplicate event, missing rights → explicit refusal. **Recovery:** content-addressed census, idempotent queue projection; no hidden re-poll. **Fixture:** multi-category, 0-market and repeated-market local archive; actual route to existing triage and read-side. **Capabilities:** R3-07, R3-07-ROUTER, R3-12-SAMPLER, R3-23/24/25/27/28, R3-02 secondary. **Measured benefit:** coverage/denominator/recall and invalid-ID rejection; no edge metric.

### A2 — Research Specialist
- **Trigger:** admitted scout/candidate requiring fact/rule evidence or unresolved contradiction. **Native work:** `source_grounding::{load_corpus,bind_rule_texts,evaluate_sources}`, `metaculus_source_archive_bridge::assess_sources`, `context_broker.build_revealed_context_set` only after blinding seal. **Input:** frozen source/market scope, independently observed times, citation allowlist and source rights. **Tools/model:** source-quality/hash deterministic; opt-in Hermes web only with approved provider; Agent-Reach/LSE/PMXT MCP gated, never implicitly inherited.
- **Output:** hash-indexed `ResearchSourcePacket` with accepted/refused sources, exact quotes, cutoff/rule ID, contradictory evidence, budget. **Consumer:** A3/A4 blind shared *facts*, native `research_cooperation`, existing Alpha source references. **Failure:** quote absent, late/circular/unlicensed source, prompt injection, missing bytes → refuse/abstain without making source true. **Recovery:** cold-verify raw source digests before any resumed task. **Fixture:** challenge HTML, reversed source dates, poisoned instructions. **Capabilities:** R3-01-SOURCE_ARCHIVE, R3-02, R3-08/13/21, R3-05-CITATIONS. **Measured benefit:** citation coverage/recall and token cost per verified source, not inferred semantic truth.

### A3 — Forecaster
- **Trigger:** precisely frozen question with appropriate independent evidence and eligible method; no real new strategy forecast before unlock. **Native work:** `forecast_evaluation::{forecast_case,freeze_cohort,bind_wp170,map_wp170_membership}`; pinned Metaculus forecast producer and native train-only Wang/Elo comparison after exact import/parity; **no model controls sampling/training labels**. **Input:** question, horizon, market/rule IDs, source cutoff and permitted historical training split.
- **Tools/model:** an actual Hermes child with at most source web tools, independent context, capped attempts; model choice policy versioned and separately approved. **Output:** signed-off *first-pass* forecast/abstention, `p_yes` only where supported, uncertainty/method/version, issuance time, quoted source IDs and child witness digest. **Consumer:** A4 after both commitments sealed, native cooperation and forecast/WP170 interface (offline fixture only). **Failure:** malformed probability, missing comparator, future outcome, double child identity → refuse; never normalize malformed confidence into fact. **Fixture:** fixed probability/abstention/labeled later-outcome dataset to test schema and train/test leakage only. **Capabilities:** R3-01, R3-10, R3-10-WANG, R3-12/18/20 secondary. **Measured benefit:** valid forecast/coverage and baseline parity; real Brier score waits post-unlock authentic resolution.

### A4 — Falsifier / Red Team
- **Trigger:** independent A3 research, disputed rule/source, high-cost or high-uncertainty task, technical/semantic attack. **Native:** `research_cooperation::{assess_question,_citation}`, `source_grounding` and `context_broker` blind/reveal. **Input:** same pre-cutoff admitted sources and question as A3 **without A3 answer, chain-of-thought or hidden conclusions**; role scope and task nonce assigned by coordinator outside model output.
- **Tools/model:** second real Hermes leaf child with separate session ID and trusted witness, restricted web toolset. **Output:** contrary hypotheses, actual disconfirming source/quote spans, methodological challenge, uncertainty, abstention; independent first-pass hash committed before reveal. **Consumer:** existing cooperation result and A3 revision/refusal; disagreement ≠ majority vote. **Failure:** own-model self-report as proof, copied A3 answer, false citations, different cutoff, missing child event → refuse. **Fixture:** planted contradiction, no contradiction, hallucinated quote, same-child injection, blind leak. **Capabilities:** R3-05 and R3-05-CITATIONS, R3-11/19/04 secondary. **Measured benefit:** detected actual fixture contradictions *and* false alarms.

### A5 — Rules & Arbitrage Specialist
- **Trigger:** rule ambiguity, related-market candidate, possible cross-venue payoff relation; no profitability research in Stages A/B. **Native:** `related_market`, `related_market_economics`, `oracle3_upstream_bridge::{load_upstream,assess_rel_core}` with real pinned `check_constraint`; resolution snapshots via PIT. **Input:** distinct condition/leg IDs, exact rule text/hash, snapshot clock, fee-class version, source finality.
- **Tools/model:** deterministic constraints/fee math; optional deep reasoning only to explain ambiguous settlement, never to declare equivalent by prose. **Output:** `RULE_VERIFIED / AMBIGUOUS / REFUSED`, complete leg graph, exact source IDs, conservative math. **Consumer:** A7/native feasibility, A4 semantic check and Alpha advisory research. **Failure:** missing leg/settlement rights, rule change, unsupported market versions → fail closed, no executable claim. **Fixture:** payout tautology/contradiction/ambiguous same-topic market; actual Oracle3 function must be called offline. **Capabilities:** R3-03/04/11/19, R3-03-FEES, R3-07-ROUTER. **Benefit:** correctly rejected false equivalence and documented fee semantics.

### A6 — Wallet Intelligence Specialist
- **Trigger:** sanitized public wallet cohort/leader observation or source-quality anomaly. **Native:** existing wallet provenance/profile/copyability module family, `src/data_layer/wallet_signal_candidate_review_report.py`, `point_in_time_market_research` and approved public trade-history sources. **Input:** public wallet IDs, market/source/event IDs, observed vs filled timestamps, coverage/survivorship groups, no private account data.
- **Tools/model:** deterministic wallet statistics and delay math first, model only for sourced explanation. **Output:** wallet cohort integrity, copy-delay/leader selection/adverse-selection flags, known missing data, no copy recommendation. **Consumer:** A1/A2/A4/A7 and Alpha advisory source/candidate record with refusal denominators. **Failure:** post-event leader selection, wash-like noise, copied unverifiable account fill → no trust. **Fixture:** leader-only historical winners, duplicate wallet, delayed fill, missing fees. **Capabilities:** R3-14, R3-27 secondary; provider rights separately gated. **Benefit:** reduced invalid wallet signal admission, not manufactured copy profitability.

### A7 — Execution Economics Analyst
- **Trigger:** non-economic candidate/relationship needs actual cost/feasibility *interface* check or fixed book replay. **Native:** `execution_feasibility.evaluator.assess_execution_feasibility`, `research_runtime.executable_edge`, WP172/WP173 read-only versions, `paper_trading.engine`, `nautilus_offline`; **Lane B separately owns** R3-15/16/17/26. **Input:** native versioned market/venue snapshot, bid/ask/depth, fee class, order constraints, gap/latency evidence, source cutoff.
- **Tools/model:** native Decimal/venue math, no freeform LLM computation of risk/fees. **Output:** `ECONOMICS_SUPPORTED / PARTIAL / REFUSED`, exact missing dimensions, conservative conditional sizes, zero real order. **Consumer:** qualification/strategy *preview* and Control Center read projection; not live order placement. **Failure:** stale/wrong protocol, missing book gaps/fees, unknown partial fills → non-authorizing refusal. **Fixture:** CTF/V2 mismatch, gap book, crossed spread, partial-fill journal. **Capabilities:** R3-09/09-BOOK_GAPS, R3-15/16/17/26, R3-03-FEES; read accepted Lane B results only. **Benefit:** reproducible after-cost calculation correctness on fixtures, not an edge claim.

### A8 — Performance & Learning Specialist
- **Trigger:** immutable *already frozen* forecast receipt paired with a later genuine outcome (only after owner unlock for new economic research), or frozen engineering outcome fixture. **Native:** `forecast_evaluation::{score_one,score_cohort}`, `learning_feedback::{score_frozen,group_diagnostics,build_proposals}`, `hermes_controlled_runtime.autonomous_feedback` and existing strategy manager read-only. **Input:** forecast head, valid outcome ledger and sealed membership denominator.
- **Tools/model:** deterministic Brier/log/calibration and cohorts, optional LLM to explain evidence-backed change, never rewrite old probabilities. **Output:** `LearningProposal` with score, abstention, denominator, source/version and bounded next-task suggestion; `REAL_OUTCOME_NOT_AVAILABLE` for synthetic only. **Consumer:** versioned non-economic coordinator research-priority proposal (owner-reviewed), A9. **Failure:** unmatched/missing/future label, score tamper, new outcome overcount → reject. **Fixture:** known scored binary outcomes, omitted/late labels, paired cohort replay. **Capabilities:** R3-06/20/22, R3-01/10 secondary. **Benefit:** correct observed scoring and measurable error attribution; not guaranteed profitability.

### A9 — Bot Improvement Engineer
- **Trigger:** CI failure, source/permission integration defect, repeated agent refusal, degraded verified accuracy/cost or deliberate periodic bounded offline technical review (not an autonomous cron until explicitly approved). **Input:** sanitized repo/CI change list, role usage/cost ledger, Control Center operational incidents, capability backlog, A8 scored summaries only; no secrets/trading account/wallet API.
- **Tools/model:** read-only static analysis and comparison to pinned upstream; model optional for code reasoning under fixed token budget. **Output:** versioned `BotImprovementProposal` with exact issue/lineage, confidence, expected benefit *hypothesis*, smallest code surface, upstream alternative, tests, falsification benchmark, permission impact, rollback, proposal hash. **Consumer:** Side25 ADOPT LOOP intake → specific future Karl-approved WP → CC/Codex → independent review → Karl merge. **Never** writes code/config/PR/branch/permissions itself. **Failure:** evidence absent or requests policy/credential/risk escalation → refuse/escalate. **Fixture:** seeded genuine CI-like failure, unsubstantiated performance claim and proposed secret modification; accept only reproducible safe proposal. **Capabilities:** R3-29/21 and cross-row reliability. **Benefit:** fraction reproducible/safely actionable and verified later improvements, not number of unmerged suggestions.

## Conditional flows, blind stages, shared evidence and failure recovery

| Case | Native prework | Specialists *only when justified* | Authority-safe terminal |
|---|---|---|---|
| Routine known market, fixed source | PIT and native eligibility/census | A1→A2; A3 when forecastable; A4 if uncertainty material; A7 for fixed economics read | Source/candidate/episode refs or abstain |
| Disputed/circular source | exact quote/hash/rule metadata | A2 + **blind** A4; A3 only after evidence repair | `SOURCE_PIT_INVALID`, no forecast promotion |
| Related-market settlement | rule leg identities, payoff matrix | A5+A4 then deterministic A7 | `RULE_AMBIGUOUS` or advisory verified relation; never trade |
| Wallet cohort | public seen-at times, selection cohorts | A6+A2; A4 adverse-selection; A7 cost read | copyability refusal/advisory with complete denominator |
| No source/provider grant | allowed host/right preflight (zero request) | none, or A2 deterministic context only | `PROVIDER_BLOCKED`, no hidden fallback |
| Fault/restart/timeout | durable task intent, reconciliation; no re-spend | only unbilled deterministic repair; A9 on sanitized incident | `UNKNOWN_QUARANTINED` until verified, no duplicate child |
| Post-outcome learning | joined authentic sealed outcomes (later) | A8; A9 if recurring software defect | suggested *versioned* future research policy, not self-update |

**Context/memory read/write:** All roles may read frozen permitted source/context with independent role-scoped secrets absent; no child gets a writeable memory or code tool. Only native verified coordinator/Alpha store writes (authoritative append) after consumer validation; research episode provenance records refer to original source and child witness rather than copying arbitrary model instruction into memory. Reveal A3/A4 results to each other only after independent first-pass commitment; old policy/context memory remains stable. Future memory efficiency improvements measured on paired fixtures; don't add vector DB without demonstrable lift.

**Restart/cost requirements:** Per attempted child record scheduled/started/completed/unknown state; provider/model usage from trusted run when possible; **UNKNOWN is not free**. Cost budgets are hard per approved provider/run and versioned; no provider alternative on 429/timeouts unless owner authorization; max one first-WP parent + two children, no recursive depth, no unbounded loops. Failures get closed codes, not raw logs, personal info or guessed costs. Composite toolsets/MCP/control escapes are individually negative-tested on actual pinned resolver.

**Acceptance hierarchy:** `ENGINEERING_VERIFIED_OFFLINE` = actual pinned upstream bytecode/function called in a network-blocked fake-model fixture and native downstream consumed. `PROVIDER_WITNESSED_RUNTIME_PROVEN` = separately authorized real technical model request, trusted parent/child events/tool identity/cost and native read. `FULL_SYSTEM_OPERATIONAL` = final frozen nine/36/host/controller/permissions/recovery acceptance, independently reviewed and Karl-approved. None proves profitable Alpha or economic access.
