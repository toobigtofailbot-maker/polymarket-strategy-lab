# Wallet And Copy-Trading Semantics

Wallet and copy trading is an experimental real strategy module, not blind copy-trading.

Only public and permitted data may be used. Hacked, leaked, private, insider, or otherwise impermissible information is forbidden.

## Terms

- Wallet tracking: observing public wallet activity for research and signals.
- Whale wallet: wallet with large observed activity or exposure.
- Smart wallet: wallet with evidence of useful historical behavior under documented metrics.
- Profitable wallet: wallet with measured positive historical performance under documented assumptions.
- Suspicious/informed-flow score from public data only: research score based only on permitted public observations.
- Watchlist: set of wallets selected for monitoring.
- Wallet score: aggregate score based on documented public features.
- Copyability score: estimate of whether a wallet event can be followed after delay, liquidity, and slippage.
- Copy delay: elapsed time between observed wallet event and proposed copy action.
- Copy slippage: price degradation between observed event and available copy price.
- Wallet attribution: process for linking public activity to a watched wallet without claiming private identity.
- Copied trade: paper or future authorized live trade derived from a wallet event.
- Missed copy trade: observed eligible event not copied due to controls or market conditions.
- Disabled wallet: wallet removed from copy eligibility by rule or review.

Live copy-trading requires explicit authorization, tiny-size limits, delay and slippage tracking, and auto-disable rules.
