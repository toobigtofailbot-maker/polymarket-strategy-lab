## What WP175N Adds

The first canonical Alpha Factory research-memory substrate: a standalone record model
(`src/data_layer/analytical_research/alpha_factory.py`) and a bounded append-only SQLite
registry (`src/data_layer/analytical_research/alpha_factory_registry.py`), exported from
the package `__init__.py`.

- Four frozen content-addressed record types (schema `1.0.0`): `ResearchSourceReference`
  (`alphasource:sha256:`), `OpportunityCandidate` (`alphacandidate:sha256:`),
  `HypothesisFamily` (`alphafamily:sha256:`), `ResearchEpisode` (`alphaepisode:sha256:`).
- Primitive multi-lane evidence (`HISTORICAL_REPEATABILITY`, `FUNDAMENTAL`, `WEATHER`,
  `CROSS_MARKET`, `RESOLUTION_RULES`, `MICROSTRUCTURE`); COMPOSITE is not stored;
  `is_multi_lane = len(evidence_lanes) >= 2` is derived; lane order never changes identity.
- Nine closed result states with a per-state evidence matrix; exact-scope negative evidence
  (never a global blacklist); append-only reopen lineage.
- Deterministic `novelty_fingerprint` (`alphanovelty:sha256:`) over closed structured
  novelty dimensions + primitive lanes (prose excluded) and `mechanism_fingerprint`
  (`alphamechanism:sha256:`) over `mechanism_key` + `mechanism_dimensions_json` (producer /
  provider / model excluded). Fingerprints are separate from record ids.
- Producer provenance (`HUMAN_RESEARCH`, `HERMES_CONTROLLED_RESEARCH`,
  `DETERMINISTIC_ANALYSIS`, `OTHER_VALIDATED_ADVISORY`) with fail-closed receipt/source
  requirements; HERMES producer status grants no authority advantage.
- Recursive bounded free-form mapping safety: binary float rejected at every depth;
  secret-like and authority-like keys rejected case-insensitively with no echo; PUBLIC_HTTPS
  locators rejected for non-https, userinfo, local/file, or secret-bearing query keys and
  never fetched.
- Separate append-only SQLite registry: format id `s10-alpha-factory-registry`, integer
  schema version 1, application id 1464877425 (proven unique; distinct from WP170's
  1464877424). Per-entry SHA-256 hash chain, append-only UPDATE/DELETE triggers,
  caller-order-independent atomic append (canonical kind rank + predecessor/reopen
  topological order), projected-history cross-reference validation, novelty/mechanism global
  uniqueness, tamper detection, exact-duplicate idempotency, read-only verified load, and
  conservative bounds.
