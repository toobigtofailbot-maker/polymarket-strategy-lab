- **Call path:** cold SRC-01 verify of a frozen grounding copy -> native `load_corpus`/`bind_rule_texts` -> PIT rule records -> `related_market.discover_candidates` (three native generators, all LOW_CANDIDATE_ONLY) -> `formal_proof` + `real_world_classification` -> `related_market_economics` over native `build_public_venue_snapshot` and evaluator helpers -> one content-addressed receipt.
- **Native discovery:** caller models only qualify discovered candidates; a manual pair is `NOT_NATIVE_CANDIDATE`. Condition-derived event ids, nonbinary, closed and oversized groups are counted noncandidates.

The 2026-11-04 native fee policy is never extended; unknown fees are never zero. Positive baskets are only `FEE_AND_DEPTH_CONDITIONAL` with atomicity NOT_PROVEN and `executable_edge` false.
