- Compensating isolation without safe mode: exact `--toolsets web`; `--ignore-rules`; a dedicated research `HERMES_HOME` whose `config.yaml` is absent and whose user plugins are absent/empty (fail-closed preflight, names only, no credential read); an ephemeral empty cwd distinct from the managed dir; `HERMES_ENABLE_PROJECT_PLUGINS` and `HERMES_MANAGED_DIR` never inherited; managed `plugins.enabled` empty and `hooks` empty; no MCP/custom toolset; no repo mount.
