## Implemented surface

- `research_dataset.py`: `materialize_canonical_pit_dataset` verifies the record
  store through the WP163 public API, re-materializes a genuine
  `DatasetSnapshotReference`, and writes deterministic derived Parquet partitions
  (`market_observations`, `source_snapshots`, `resolution_rule_snapshots`,
  `review_conflicts`) preserving the ordinary/review role split. The logical
  dataset identity is derived from canonical record content and explicit
  record-version-id row order and is independent of physical Parquet bytes and
  output path; physical integrity evidence (file SHA-256, byte length, schema
  fingerprint) is recorded separately, and `verify_partition_file_integrity`
  detects corruption. DuckDB helpers are lazy-imported; Polars helpers scan
  lazily. `check_analytical_runtime` proves the exact pins and Python floor via
  packaging metadata without importing the DuckDB native module.
- `external_dataset.py`: `build_external_dataset_descriptor` produces a frozen,
  deterministic, path-independent `ExternalDatasetDescriptor` whose identity is
  order-independent over source objects and event types but sensitive to any
  source-byte mutation; absolute-path object names are rejected.
- `pmxt_v2.py`: `validate_and_describe_pmxt_v2_archive` validates explicitly
  supplied local pmxt v2 Parquet files with bounded batched scans (schema, event
  types, UTC timestamps, decimal/side semantics), records per-file content hashes
  and a shared schema fingerprint, derives UTC coverage, and always classifies the
  source `THIRD_PARTY_NATIVE_FRAME_ARCHIVE`; a native-official-capture request is
  refused. No URL, HTTP, API, object-store SDK, or downloader is used.
