## Capability Contract

WP175H adds a dormant-by-default, deterministic control plane around one bounded,
one-shot, web-only EXTERNAL Hermes research session pinned to Hermes Agent v0.21.3
(tag v2026.9.14, commit 345cd2b). It provides an immutable content-addressed
request, a frozen non-broadenable invocation policy (exactly the `web` toolset =
web_search + web_extract), a compact research envelope, a backend protocol with a
deterministic no-process fake and an isolated argv-only ephemeral-cwd external
backend, a bounded plain-stdout response and usage-file parser, an authoritative
untrusted-draft schema/safety validator, and a sanitized no-authority receipt
requiring human review. The external contract is verified against the exact tagged
v0.21.3 source (`hermes_cli/_parser.py`, `hermes_cli/oneshot.py`,
`agent/usage_pricing.py`, `toolsets.py` @ 345cd2b): the top-level `-z` one-shot path
carries only supported top-level flags and exposes NO iteration cap (`--max-turns`
is chat-subparser only and `-z` sets no `max_iterations`), so no `max_turns` field or
flag exists (`iteration_cap = UNAVAILABLE_ON_PINNED_V0_21_3_ONESHOT`). The frozen
first-runtime policy performs ZERO automatic paid research retries
(`max_transport_retries = 0`). Success requires, in order, process exit code 0, a
valid usage report as mandatory success evidence (`completed`/`failed`/token/
api-call/label validity), authoritative draft schema/safety validation, verified
provider/model binding (usage == request), and a POST-RUN cost-acceptance gate whose
`cost_status`/`cost_source` read the exact tagged vocabulary and treat missing/unknown
cost as `COST_EVIDENCE_UNAVAILABLE` (never zero). `-z` internally bypasses approvals,
so safety rests on the web-only tool surface, safe-mode, and the deterministic
no-authority validator, not on approval prompts. Hermes output is untrusted bytes;
the repository validator is authoritative and fails closed with no raw payload,
stderr, environment, secret, or path in canonical evidence.

This package creates no opportunity candidate, probability thesis, fair value,
side, entry/exit, position size, strategy promotion, Alpha Factory state, WP170
experiment, or trade recommendation. WP170/WP172/WP173/WP175 semantics and the
legacy WP99/WP133/WP145 advisory validators/harness are unchanged.
