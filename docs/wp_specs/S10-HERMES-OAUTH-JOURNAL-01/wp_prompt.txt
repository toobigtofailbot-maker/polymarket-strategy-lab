# 1. OBJECTIVE / KARL'S AUTHORIZATION
Objective: hosted CI run 39048125375 (PR #244, compat ubuntu-24.04 / py3.14) failed in test_oauth_one_post_crash_replay_no_retry. In its six-thread step, one losing caller returned JOURNAL_INVALID. The cause is a pre-existing race in merged src/research_runtime/hermes_controlled_runtime/oauth_plan_stage_b.py. run_oauth_attempt published the terminal journal with open("xb") and then wrote it. A concurrent caller could see the file exist while it was still empty or partial, fail to parse it and fail closed. Exactly one dispatch still occurred.

On 2026-10-17 Karl authorized the smallest governed, separate WP/PR to repair this from clean main:
- write the terminal completely to a same-directory temporary file, flush and fsync it, and publish it atomically;
- add a deterministic concurrency regression;
- run focused tests, native readiness and the required hosted CI;
- publish one PR, and do not merge. Karl alone merges.

# 3. CHANGED-FILE SCOPE (EXACTLY FIVE)
1. src/research_runtime/hermes_controlled_runtime/oauth_plan_stage_b.py — add _publish_terminal and call it in place of the direct exclusive-create write.
   - Write to tempfile.mkstemp in the journal directory, flush, os.fsync, then os.link into the terminal path. The link is atomic and never overwrites, so FileExistsError keeps an existing terminal immutable.
   - Always unlink the temporary file.
   - A crash before the link leaves only the reservation. ATTEMPT_ALREADY_RESERVED then blocks any further dispatch.

# 4. ACCEPTANCE AND EVIDENCE PLAN
R001: test_oauth_terminal_publication_is_atomic.
- The writer pauses deterministically after fsync and before publication.
- While it is paused, the terminal is invisible and three concurrent callers each get ATTEMPT_ALREADY_RESERVED, never JOURNAL_INVALID.
- After release the terminal is complete and verifies, replay redispatches nothing, and exactly one dispatch occurs.
- Publication onto an existing terminal raises and leaves its bytes unchanged.
- A crash before publication leaves no terminal and no temporary file, and the next call is ATTEMPT_ALREADY_RESERVED with zero dispatch.

R002: test_oauth_one_post_crash_replay_no_retry passes unchanged. That covers one dispatch per outcome, cold replay, interrupted reservation, a tampered terminal giving JOURNAL_INVALID, and six concurrent callers giving one dispatch.
