2. OBJECTIVE
===============================================================================

Make the merged WP175H external runtime capable of running pristine pinned Hermes
v0.21.3 under one mechanically enforced CONTROLLED RESEARCH PROFILE while preserving
the original authority boundary.

The correction: keeps exact pinned Hermes v0.21.3 pristine; keeps the top-level -z
one-shot; keeps --ignore-user-config and --ignore-rules; REMOVES --safe-mode from the
real research invocation because on exact tagged v0.21.3 it sets HERMES_SAFE_MODE=1 and
makes hermes_cli/plugins.py skip plugin discovery, suppressing the bundled
plugins/web/firecrawl backend H1 requires; replaces the lost safe-mode protection with
a deterministic, repo-owned, non-secret managed-scope config.yaml injected through an
ephemeral HERMES_MANAGED_DIR; forces Firecrawl for both web_search and web_extract;
forces keyless fallback and keyless rescue off; forces the fallback-provider chain
empty; sets one ordinary provider attempt (agent.api_max_retries 1); explicitly allows
only the pinned same-provider primary transport recovery; keeps the exact web-only
toolset; prevents user/project/custom plugins, MCP, hooks/rules/memory, and repo
context from expanding the H1 surface; retains the WP175H usage/cost/provider/model/
output/safety fail-closed semantics; and makes no real provider or web calls during
implementation or CI.

Verified against exact tagged Hermes v0.21.3 (tag v2026.9.14, commit 345cd2b, via
read-only source inspection with zero runtime/provider call): the -z one-shot
(hermes_cli/oneshot.py) calls hermes_cli.config.load_config(), whose
_merge_managed_overlay deep-merges the managed config leaf-over-leaf on top of
defaults, so the managed layer survives the one-shot path; get_managed_dir() honors
HERMES_MANAGED_DIR only when the directory exists; config.yaml is parsed with
yaml.safe_load so canonical JSON is valid; tools/web_tools.py resolves
web.search_backend / web.extract_backend strictly with no probe; the keyless ring and
one-shot rescue read web.keyless_fallback / web.keyless_rescue; fallback_config reads
fallback_providers; agent_init clamps api_max_retries to one ordinary attempt and the
primary OpenAI client sets SDK max_retries 0; agent_runtime_helpers permits one bounded
same-provider primary transport recovery; and plugins_discovery auto-loads the bundled
Firecrawl backend while gating non-bundled plugins on the plugins.enabled allow-list
and project plugins on HERMES_ENABLE_PROJECT_PLUGINS.

5. FROZEN CONTROLLED-PROFILE DESIGN
===============================================================================

Research argv becomes exactly: hermes --ignore-user-config --ignore-rules --provider P
--model M --toolsets web --usage-file <bare relative name> -z <bounded prompt>.
--safe-mode MUST NOT appear.

For every external research invocation the backend creates a fresh ephemeral
managed-scope directory (distinct from the empty cwd, the repository, local_data, and
the research HERMES_HOME), writes exactly one non-secret config.yaml holding the
deterministic managed bytes, and sets HERMES_MANAGED_DIR itself (never inherited, never
caller-supplied). Both ephemeral directories are removed on success, timeout, and
launch failure.

The managed overlay mechanically freezes at least: updates.check false;
fallback_providers empty; agent.api_max_retries 1; web.backend / web.search_backend /
web.extract_backend firecrawl; web.keyless_fallback false; web.keyless_rescue false;
web.cache_enabled false; web.provider_tier.firecrawl paid; plugins.enabled empty; hooks
empty. The deterministic managed-config bytes (canonical JSON, valid YAML) or their
SHA-256 are committed into the policy identity, and the Hermes invocation policy schema
is bumped to 2.0.0 because the security posture materially changed.

The dedicated research HERMES_HOME is validated fail-closed before spawn: config.yaml
absent; user plugin directories absent or empty; no repo/local_data/traversal/symlink;
an .env/auth.json credential store alone is permitted, inspected by name only, never
read or echoed. Custom/user/project plugin loading is FORBIDDEN; pinned bundled backend
discovery is ALLOWED for web provider registration; the exposed agent toolset is
WEB_ONLY.

Retry posture (canonical): exactly one research invocation per attempt; zero WP175H
outer transport retries; one ordinary provider attempt via agent.api_max_retries 1; no
provider/model fallback; no web-backend fallback/rescue; and one bounded same-provider
primary transport recovery permitted by exact tagged v0.21.3, documented and never
suppressed by a Hermes fork.
