Negative-Test Matrix:
  - A PUBLIC_HTTPS locator with a secret-bearing query key, userinfo, http/file scheme, or
    localhost is rejected and never fetched.
  - An unknown or duplicate evidence lane is rejected; COMPOSITE is never a stored lane.
  - Every result state without its required supporting evidence field fails closed
    (RESULT_EVIDENCE_INVALID), and every episode without falsification checks or any
    evidence reference fails closed.
  - A REOPEN_TRIGGERED episode without a resolvable prior episode of the same
    candidate/family, or targeting a RESEARCH_SUPPORTIVE/REOPEN_TRIGGERED episode, is
    rejected; no old record is mutated.
  - A nested secret-like or authority-like key, or a binary float at any depth, is rejected
    with no echo of the rejected key/value/payload.
  - A second non-identical candidate with the same novelty fingerprint, or a second
    non-identical family with the same mechanism fingerprint, is rejected against existing
    and projected history.
  - A batch with one bad record commits zero rows and leaves the head hash and row count
    unchanged; caller batch order never changes the committed bytes.
