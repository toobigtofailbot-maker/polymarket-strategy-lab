===============================================================================
0. EXECUTION INTENT
===============================================================================

Build the first production-shaped, repo-owned deterministic control plane around
one bounded, one-shot, web-only EXTERNAL Hermes research session. Deterministic
code continues to own validation, evidence integrity, budget, and no-authority
controls; Hermes is an untrusted research brain, not an execution authority.

This package is NOT the Alpha Factory. It provides a narrow reusable primitive:
validated ResearchRunRequest -> deterministic bounded Hermes invocation plan ->
one ephemeral one-shot session -> web-only tool posture -> bounded plain-stdout
response and usage-file capture -> untrusted final research draft -> deterministic schema/safety
validation -> sanitized ResearchRunReceipt -> mandatory human/deterministic review.

It creates no opportunity candidate, probability thesis, strategy family, Alpha
Factory state, WP170 experiment, or trade recommendation. Code-complete is not
runtime-activated; the first real provider-backed run is separately gated as
S10-GATE-H1.

3. PINNED EXTERNAL CONTRACT
===============================================================================

External runtime: NousResearch/hermes-agent.
Required runtime version: Hermes Agent v0.21.3; release tag v2026.9.14; release
commit 345cd2b; release date 2026-09-14. Do not integrate against main, an
unpinned rolling tag, or latest.

Frozen one-shot command shape (argv only, never a shell string), matching the
exact tagged v0.21.3 CLI (verified against hermes_cli/_parser.py and
hermes_cli/oneshot.py @ 345cd2b). v0.21.3 does NOT support --format stream-json or
--input-file; it carries the prompt as the -z argv element and writes machine-
readable usage/cost to --usage-file. --max-turns is NOT a top-level flag (it exists
only on the chat subparser) and the tagged -z path sets no max_iterations override,
so there is no iteration cap on the pinned one-shot path and none is passed:
  hermes --safe-mode --ignore-user-config --ignore-rules
    --provider <label> --model <label> --toolsets web
    --usage-file <bare-name> -z <deterministic-research-envelope>
Version is read from a bounded `hermes --version` preflight run in an isolated
throwaway HERMES_HOME whose config sets updates.check=false (raw --version otherwise
does a passive GitHub update check per tagged _startup_fast.py). Require: launched,
not timed out, exit 0, stdout not truncated, semver == 0.21.3.

Initial allowed built-in toolset: EXACTLY web (web_search + web_extract). Forbidden
tool families: terminal, file, browser, code_execution, delegation, memory,
session_search, cronjob, messaging, Home Assistant, project, MCP servers, plugins,
shell hooks, arbitrary skills, X authenticated tooling, and any trading/account/
wallet integration. The composite safe toolset is not used. The repository
validator is authoritative; Hermes output is untrusted bytes until local
validation passes.

REAL_HERMES_BINARY_NOT_PRESENT on this machine is recorded as an activation
prerequisite, not a code blocker: tests use a fake executable and make zero
paid/provider calls.

6. RUNTIME REQUEST / POLICY / OUTPUT / RECEIPT CONTRACT
===============================================================================

Request: immutable content-addressed HermesResearchRunRequest with research
question/objective/category, public market context, allowed research scope,
required source types, per-run caps (max_sources, max_wall_seconds,
max_output_bytes, max_accepted_estimated_cost_usd; no max_turns because the pinned
one-shot path exposes no iteration cap), non-secret provider/model labels,
human_review_required, and non_authority_notice. Validation rejects unknown fields,
binary floats where numeric canonicality matters, over-bound values, path
traversal/absolute paths, embedded secrets, and any trading/risk/credential/
scheduler/file/shell authority escalation, without echoing rejected content.

Policy: immutable non-broadenable HermesInvocationPolicy pinned to v0.21.3 with
exactly the web toolset, ignore-user-config, ignore-rules, safe-mode, one-shot,
plain-stdout+usage-file output, shell false, ephemeral empty cwd, repo mount false, and no
mcp/plugin/cron/delegation/browser/file/terminal/code-execution; max transport
retries 1; max concurrency 1.

Process boundary: a HermesInvocationBackend protocol with a deterministic no-
process fake backend and an external CLI backend that runs argv only from a fresh
empty temp cwd, never mounts the repo/local_data/home path, caps stdout/stderr,
enforces a hard wall-clock timeout with best-effort tree kill, deletes the temp
directory on teardown, and handles no provider credential.

Output: Hermes returns one JSON research draft with summary, evidence for/against,
uncertainties, known missing data, falsification checks, limitations, what would
change the conclusion, bounded source references, suggested next steps, a
confidence label, and every no-authority flag (advisory_only, human_review_required,
no_execution_authority, no_risk_override, no_credential_request,
no_order_or_cancel_or_sign_or_submit, no_paper_live_decision,
no_strategy_promotion_approval, no_pr_approval_or_merge_readiness_claim). Invalid
JSON/schema fails closed; there is no try-again-until-it-passes. No fair
probability, expected return, side, entry/exit, position size, executable trade,
strategy promotion, or Alpha candidate id is produced.

Receipt: immutable sanitized HermesResearchRunReceipt binding request/policy ids,
exact Hermes version, reported provider/model labels, UTC bounds, terminal status,
transport attempts, timeout/truncation flags, tool-call counts, source url count
and digests, output/safety validation status, token/cost if available, budget
status, human_review_required true, all execution/live/credential/risk/paper
authority flags false, and activation_state in
{CODE_COMPLETE_NOT_REMOTE_ACTIVATED, CONTROLLED_RESEARCH_RUN_COMPLETE}. The canonical
receipt never contains an API key/token, auth header, environment dump, raw stderr,
raw provider payload, home/repo path, private data, trading credential, or order/
account state.
