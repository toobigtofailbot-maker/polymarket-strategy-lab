## 4. Contracts

- Sources: result.is_valid and an AlphaFactoryRegistrySnapshot / AlphaDiscoveryRegistrySnapshot are
  required; any unconfigured/missing/wrong-suffix/tampered/wrong-schema/internal failure -> 503
  SOURCE_UNAVAILABLE only. Sources are independent.
- Routes: GET /api/alpha/memory, /api/alpha/candidates, /api/alpha/candidates/{candidate_id},
  /api/alpha/episodes/{research_episode_id}, /api/alpha/discovery/queue,
  /api/alpha/discovery/triage/{market_triage_decision_id}; total /api routes 24.
- IDs: ^alphacandidate:sha256:[0-9a-f]{64}$, ^alphaepisode:sha256:[0-9a-f]{64}$,
  ^alphatriage:sha256:[0-9a-f]{64}$; malformed 400 before source access; valid absent 404; never echoed.
- Memory summary: head_entry_hash, total_rows, total_payload_bytes, four record counts, no-authority
  flags; empty valid registry -> 200 with null head and zero counts.
- Candidates: registry sequence DESC, candidate_id ASC; limit default 50, 1..100, duplicate/unknown
  keys 400; is_multi_lane = len(evidence_lanes) >= 2 (never COMPOSITE).
- Lineage: same-candidate episodes; families referenced by them (sequence ASC); an episode is a
  research leaf unless another episode of the same (candidate, family) names it as predecessor or
  reopened; multiple leaves allowed; never labelled qualified/approved/tradeable.
- Episode detail: full canonical evidence text; source refs resolved only from the same snapshot
  (unresolvable -> SOURCE_UNAVAILABLE); deterministic_evidence_refs opaque; source_locator is text only.
- RESEARCH_SUPPORTIVE != QUAL_PASS / qualified / OOS positive / executable edge / profitable / paper,
  live or Gate-C ready. Negative states are exact-scope records, never global blacklists.
- Discovery queue: latest recorded queue = greatest Discovery registry sequence (no wall clock); none
  -> 404. Policy, universe and triage resolved from the same snapshot; lanes core / exploration /
  audit / deferred / skipped_ineligible / skipped_capacity in canonical array order;
  coverage_scope BOUNDED_OBSERVED_UNIVERSE, external_universe_completeness UNPROVEN; audit_seed omitted.
- Triage detail: triage, bounded universe market, optional material change, alpha_memory_resolution
  with status NOT_BOUND (triage head null) / UNAVAILABLE (Alpha unconfigured or unverifiable) /
  HEAD_MISMATCH (verified head != bound head; nothing resolved) / RESOLVED (exact head match; only
  matched_* ids; a missing matched id -> SOURCE_UNAVAILABLE). No fuzzy or textual join.
- Frontend: routes /overview /markets /experiments /strategies /hermes /alpha /paper /audit; keys
  ["cc","alpha","memory"], ["cc","alpha","candidates","list"], ["cc","alpha","candidates","detail",id],
  ["cc","alpha","episodes","detail",id], ["cc","alpha","discovery","queue"],
  ["cc","alpha","discovery","triage",id]; retry false, no focus/reconnect refetch, staleTime Infinity,
  no polling; Refresh invalidates only alpha; component-local tabs; wording "latest recorded
  discovery queue", never live/current/real-time.
