## 7. Backend read-model contract

Create `src/operator_cockpit_ops.py`.

It defines its own closed projection error type and pure projection function(s). It may import
only public StrategyLifecycle records/helpers needed for this read projection, including:
`RISK_BANDS`, `StrategyLifecycleSnapshot`, `load_strategy_lifecycle_store`,
`evaluate_portfolio_capacity`. It must not import the paper, execution-gateway, LIVE-ORCH,
Gate-C, EXEC-FEAS, deployment or network families.

Source rule:
- `strategy_lifecycle_path` is required for `/api/ops/portfolio`;
- load only through `load_strategy_lifecycle_store(path)`;
- require `result.is_valid` and a non-null `StrategyLifecycleSnapshot`;
- any unconfigured, missing, invalid-path, wrong-schema, tampered, malformed or unexpected
  source/projection failure -> `503 SOURCE_UNAVAILABLE` only;
- no path, exception text, raw store value or traceback is emitted;
- reads leave source bytes unchanged.

Evaluation time:
- `operator_cockpit.py` captures exactly one `time.time_ns()` value per
  `/api/ops/portfolio` request after query validation;
- passes that exact integer to the projection;
- the projection calls `evaluate_portfolio_capacity(snapshot, evaluated_at_ns)` exactly once;
- the same value drives every allocation `active_at_evaluation` check and response
  `evaluated_at_ns`;
- browser time never drives capacity semantics.
