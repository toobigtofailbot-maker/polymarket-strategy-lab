## 7. Backend transport contract

Create `src/operator_cockpit_stream.py` as a transport-only module.

Frozen constants:

```text
STREAM_SCHEMA_VERSION = "1.0.0"
BASE_TICK_SECONDS = 5
STREAM_EVENT_KINDS = ("RESYNC_REQUIRED", "REFRESH_DUE", "HEARTBEAT")
STREAM_FAMILY_REFRESH_SECONDS = {
  "overview": 10,
  "market": 5,
  "experiments": 30,
  "strategies": 30,
  "hermes": 30,
  "alpha": 30,
  "ops": 5,
  "paper": 5,
  "audit": 10,
}
```

Important: `market` is the existing `QueryFamily` token; `/markets` remains the frontend route. Do not introduce a parallel `markets` family token.

The module may use standard-library async/time/UUID/JSON/typing helpers only. It must not import `sqlite3`, canonical domain/store modules, FastAPI/Starlette request models, filesystem/path/env/subprocess/network-client modules or WebSocket libraries.

Use deterministic internal test seams for sleeper, clock and connection-id factory; production defaults remain `asyncio.sleep`, `time.time_ns` and UUID4-derived IDs. Test seams are not exposed through HTTP, CLI, env or config.

Connection id grammar:

```text
ccstream:<32 lowercase hex>
```

Every new connection:
1. creates a fresh connection id;
2. starts `sequence = 1`;
3. emits `RESYNC_REQUIRED` immediately;
4. then waits on the 5-second base tick;
5. emits `REFRESH_DUE` when the selected family cadence is due, otherwise `HEARTBEAT`;
6. increments sequence by exactly one per emitted event;
7. terminates on disconnect/cancellation without internal retry or background continuation.

The loop exists only while that HTTP request is connected. No app-start/global background task.

Event JSON has exactly:

```text
schema_version
connection_id
sequence
kind
family
server_time_ns
```

`server_time_ns` is a decimal string, not a JSON number. Transport sequence is positive integer and connection-local only.

SSE framing:

```text
id: <connection_id>:<sequence>
event: resync|refresh|heartbeat
data: <compact JSON envelope>

```

No `retry:` directive. No domain payload. No path/error/secret/private data.

`REFRESH_DUE` means only server cadence says to re-fetch. It does not mean source changed or data is fresh/stale. `HEARTBEAT` means only transport emitted a scheduled connection event.

## 10. Reconnect / gap / resync rules

There is no replay buffer and no persistent transport history.

`Last-Event-ID` is not used to resume prior connection history. A reconnect starts a new server connection id and the first server event is always `RESYNC_REQUIRED`.

Frontend state for one EventSource object tracks only current transport connection id and last sequence.

Rules:
- first valid event / changed connection id -> resync active family;
- same connection + `sequence == last_sequence + 1` -> normal processing;
- same connection + any other sequence -> transport gap -> resync active family;
- after resync, the newest valid event becomes the local transport baseline;
- a transport gap is never labeled a market-data gap;
- no attempt is made to replay canonical domain events.
