5. SANITIZED STDERR CONTRACT
===============================================================================

Implement a private deterministic sanitizer in runner.py (no import from tools/).
MAX_SANITIZED_STDERR_EXCERPT_BYTES = 4096. Closed statuses: EMPTY, AVAILABLE,
AVAILABLE_REDACTED, BLOCKED_UNSAFE, SANITIZER_ERROR.

Behavior: (A) decode UTF-8 fail-closed (replacement chars, never raise); (B) normalize
CRLF/CR to LF and strip NUL/unsafe control chars; (C) redact secret-bearing structures
BEFORE truncation — named/JSON key=value secret assignments (api_key, private_key,
secret, clob_secret, clob_pass_phrase, password, pass_phrase, mnemonic, token,
access_token, refresh_token, id_token, ...), Authorization/Bearer/Basic material, PEM
private-key blocks and orphan headers, known token prefixes (sk-, ghp_, github_pat_,
xox*), JWT-shaped tokens, URL userinfo, and URL query/fragment material; (D) scrub
local filesystem identity (user home, repo, research HERMES_HOME, ephemeral cwd,
managed dir, Windows drive/UNC paths, /home, /Users, temp paths) to <PATH> without
exposing the username; (E) bound AFTER sanitization to a <= 4096-byte UTF-8 TAIL and
record whether it was shortened; (F) fail closed — a conservative residual secret-like
check yields BLOCKED_UNSAFE with no excerpt, and any sanitizer exception yields
SANITIZER_ERROR with no excerpt. No sanitizer failure may alter process-exit
classification or cause a retry.
