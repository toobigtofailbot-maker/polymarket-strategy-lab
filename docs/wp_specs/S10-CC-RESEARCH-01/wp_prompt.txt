## 1. Objective

Extend the merged Control Center foundation with the first V2.1 research vertical: verified
StrategyLifecycle store + verified Hermes strategy-manager store -> repo-owned bounded read-model
projection (src/operator_cockpit_research.py) -> four GET-only FastAPI routes -> typed Control Center
API / TanStack Query -> Strategies and Hermes workspaces. StrategyLifecycle state != Hermes soft
judgment != portfolio authority != EXEC-FEAS != Gate-C eligibility != LIVE-ORCH admission != order
authority. The UI explains these distinctions and never collapses them.

## 4. Contracts

- Sources: load_strategy_lifecycle_store(path) with a valid non-null snapshot; load_hermes_strategy_manager_store(path).
  Any loader/path/schema/tamper/internal failure or unconfigured required source -> 503
  {"error":{"code":"SOURCE_UNAVAILABLE"}} only. Strategy definition and adaptive bounds decode only via
  existing lifecycle parse_strategy_spec / parse_adaptive_bounds.
- Routes: GET /api/strategies, /api/strategies/{strategy_version_id}, /api/hermes/assessments,
  /api/hermes/assessments/{assessment_id}. Lists: limit default 50, 1..100, duplicate/unknown keys 400.
- IDs: ^strategyversion:sha256:[0-9a-f]{64}$ and ^hermesstrategyassessment:sha256:[0-9a-f]{64}$;
  malformed 400 INVALID_INPUT, absent 404 NOT_FOUND, raw id never echoed.
- Ordering: strategies created_time_ns DESC, strategy_version_id ASC; assessments decision_time_ns DESC,
  assessment_id ASC; limit after sort; count = returned items.
- Context status: CURRENT iff version exists and stored strategy_lifecycle_context_sha256 ==
  strategy_lifecycle_context_fingerprint(snapshot, id); STALE_CONTEXT iff exists and differs;
  TARGET_MISSING iff absent. Display only; never approval, eligibility or authority.
- Latest assessment: only the manager snapshot latest_assessment_by_strategy_version mapping. Hermes
  unconfigured/unavailable -> strategy routes still 200 with latest_hermes_assessment null.
- Lineage: exact parent ids root -> target, same family, bounded cycle/length guard, fail closed.
- Hermes DTOs: no raw model output, prompt, hidden reasoning; non_authority flags exposed; run metadata
  resolved by exact run_record_id from the same snapshot.
- Alpha: no Alpha Factory import, mapping or inference; Alpha/Evidence is S10-CC-RESEARCH-02.
- Frontend: routes /overview /markets /experiments /strategies /hermes /paper /audit; query keys
  ["cc","strategies","list"], ["cc","strategies","detail",id], ["cc","hermes","list"],
  ["cc","hermes","detail",id]; retry false, no focus/reconnect refetch, staleTime Infinity, no polling;
  Refresh invalidates only the active family; selection component-local; no action controls.
