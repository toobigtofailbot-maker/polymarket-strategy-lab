- UNKNOWN_INDEPENDENCE

Rules:
- an explicit PIT-admissible market-context independence_group_id is required for meaningful independent sample claims;
- repeated activity does not create repeated independent trials;
- for an exact condition/token inside one independence group, keep the EARLIEST eligible BUY by (event_time, wallet_event_id) as that condition/token episode;

- max_group_episode_share = max(group_episode_count / total_eligible_episodes);
- HHI = sum(share^2);
- concentration is diagnostic only; it never changes event weights.

All decimal calculations use Decimal, never binary float.

14. DIRECTIONAL SKILL / SHRINKAGE CONTRACT
===============================================================================

Directional skill uses only eligible historical BUY episodes.

Eligibility requires ALL:
- reconciled canonical event;
- canonical_event_type == TRADE_FILL;
- side == BUY;
- PIT ADMISSIBLE by profile.as_of;
- DQ == OK;
- replay_fidelity in EXACT or FAITHFUL;
- event_time inside derived evaluation window;
- exact matching WalletProfileMarketContext;
- context instrument_class == STANDARD_BINARY_OUTCOME;
- independence_group_id present;
- price present and in [0,1];
- resolved_token_value exactly "0" or "1";
- resolution evidence ADMISSIBLE by profile.as_of;
- decisive resolution-availability time exists;
- event_time < decisive resolution-availability time.

SELL is not treated as a negative directional bet in v1 because current evidence cannot distinguish entry, reduction and exit reliably enough.
COMBO_POSITION / OTHER / UNKNOWN are not directional-skill episodes.
A TRADE_FILL alone does not create a directional archetype.

Per condition/token episode:
  signed_entry_residual = resolved_token_value - entry_price

Within one independence_group_id:
- one earliest episode per exact condition/token;
- group_signed_residual = arithmetic mean of those episode residuals;
- > 0 => group success
- < 0 => group failure
- == 0 => neutral/uninformative

Across groups:
- equal weight per independent group;
- mean_signed_entry_residual = arithmetic mean of group_signed_residual;
- neutral groups do not enter success/failure Beta counts.

Jeffreys regularization:
  alpha = successes + 0.5
  beta = failures + 0.5
  posterior_mean = alpha / (alpha + beta)
  posterior_variance = alpha * beta / ((alpha + beta)^2 * (alpha + beta + 1))

Numeric determinism:
- Python Decimal only;
- local calculation precision = 50;
- exported derived decimals quantized to 18 decimal places using ROUND_HALF_EVEN;
- serialize fixed-point without exponent, trim trailing zeros and a trailing decimal point, preserving "0";
- binary float anywhere in canonical input/output is rejected.

DirectionalSkillEvidence status:
- ESTIMATED_UNCALIBRATED when at least one non-neutral independent group exists;
- INSUFFICIENT_DIRECTIONAL_EVIDENCE when no non-neutral group exists;
- UNKNOWN_INDEPENDENCE when independence grouping is unavailable.

Explicit semantics:
- the Jeffreys result is a deterministic shrinkage summary of historical group correctness;
- it is NOT a calibrated probability that the wallet will be correct in the future;
- it is NOT statistical significance;
- it is NOT a universal skill score;
- it creates NO SKILLED / UNSKILLED / PROMOTED status;
- no universal minimum-n, HHI, posterior or promotion threshold is frozen in this WP.

Raw realized/unrealized PnL, absolute trade size, leaderboard rank, rewards/rebates and current positions MUST NOT become skill authority.
