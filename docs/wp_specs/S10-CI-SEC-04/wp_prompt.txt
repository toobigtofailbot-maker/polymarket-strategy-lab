## 1. Objective

`S10-CI-SEC-02-D001` is open: hosted CI installs no gitleaks binary, so the five binary-backed
detection cases in `tests/test_gitleaks_secret_scan_gate.py` skip on hosted runners and no hosted
secret scan runs. PR #247 restored real detection rules (`[extend] useDefault = true`, no allowlist,
20 exact fingerprints) but enforcement stayed local.

Make real secret detection mandatory and fail-closed inside the already-required `ci-final-gate`
job (ruleset `main-protection` requires it): install the pinned official gitleaks 8.27.2 Linux x64
release with strict SHA-256 verification before extraction, run a redacted full-history git scan
with the committed configuration, and execute the five existing binary-backed cases with zero
skips, all before the unchanged final plan verification. No new job or workflow, no routing,
classifier, ruleset or scanner-configuration change. PR #246 is not modified.

## 4. Frozen Implementation Design

### A. Exact head and full history

Inside `ci-final-gate`, after checkout (unchanged `ref: head.sha`, `fetch-depth: 0`,
`persist-credentials: false`): require `git rev-parse HEAD` equal to the event head SHA, a
non-shallow repository, the base commit present and base an ancestor of head.

### B. Pinned, strictly verified acquisition

Under `set -euo pipefail`: download the archive and the checksum manifest with
`curl -fsSL --proto '=https' --tlsv1.2 --retry 3 --max-time`; verify the manifest against its pinned
SHA-256; require exactly one manifest entry for the archive name, a 64-hex value equal to the pinned
archive SHA-256; verify the archive with `sha256sum --check --strict` before `tar` extracts only
`gitleaks` into `$RUNNER_TEMP`; require `gitleaks version` to print `8.27.2`; add the directory to
`$GITHUB_PATH`. No install script, `latest`, cache, global install, `sudo`, tracked binary,
`continue-on-error`, `|| true` or step condition.

### C. Real history scan

`gitleaks git --redact --no-banner --exit-code 1 --log-opts="--all" .` with the committed
`.gitleaks.toml` and `.gitleaksignore` (both must exist). The step logs the truthful denominator
(non-merge commits reachable from fetched refs; `refs/pull/*` are not fetched). No `dir` substitute.

### D. Five binary-backed cases, zero skips

Install `pytest>=8.0` and run exactly the four test functions with `--junitxml` under
`$RUNNER_TEMP`; require the JUnit testsuite to report `tests="5"`, `skipped="0"`, `failures="0"` and
`errors="0"`.

### E. Order

A, B, C and D run before the existing `Verify exact plan and required job results` step, which stays
the last step and alone prints `CI_FINAL_GATE_PASS`.

### F. Regression owner

Extend only `tests/test_codex_workflow_docs.py`, reusing `_ci_jobs`: a gate checker plus positive
tests and a negative mutation matrix. Every existing workflow assertion stays.

### G. Documents

Gate doc: hosted enforcement, provenance, scope, limits and fail-closed semantics. Deferred log: only
`S10-CI-SEC-02-D001` moves to an implemented-on-branch state (not resolved before merge). Status
entry: stable, non-self-referential; live values in the PR body.
