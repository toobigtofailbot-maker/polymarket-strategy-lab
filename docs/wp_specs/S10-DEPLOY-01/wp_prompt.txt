verify-release, host-manifest, telemetry, backup, restore-verify, research-smoke-evaluate,
and verify-firewall
subcommands. Release identity is exact-HEAD, tracked-files-only, deterministic canonical hash
inventory, no absolute local identity, no credential-like payload, and no added/missing/
tampered/symlink-escape content. Host/telemetry output excludes IP, hostname, username,

Telemetry rotates at 10 MiB with seven retained files. Backups reject secret, DATA-03 and symlink paths; use SQLite online
backup for *.sqlite3. Restore writes only to an isolated restore drill, checks every hash and

--expected-sha and --ssh-port. It admits Ubuntu 24.04 x86-64 only, requires 4 CPUs, 7.5 GiB RAM,
70 GiB disk, NTP, exact release verification, the polymarket no-login user, frozen directory
layout, a per-release venv with the base project installed from existing metadata (no cockpit
extra), pip check, exact unit install and systemd-analyze verify. Expected operational failures
emit sanitized terminal JSON with stable closed codes. It rejects pre-existing conflicting inbound
UFW allows, permits the supplied SSH TCP port before enabling UFW deny-inbound and allow-outbound,
then proves the effective inbound allow set is that exact TCP port only (IPv4/IPv6 equivalent),
never changes sshd, atomically updates /opt/polymarket/current, starts only
the research target and telemetry timer, writes a host manifest, and emits sanitized JSON.

The research slice is CPUWeight=25, CPUQuota=250%, MemoryHigh=4G, MemoryMax=5G, IOWeight=25.

first runs within 60 seconds, and repeats exactly every 60 seconds. No product service exists.
