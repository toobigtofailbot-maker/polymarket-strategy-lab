## 2. EXTERNAL B0 SEMANTICS

`EXTERNAL_PIT_MARKET_PROBABILITY_V1` uses the **same parameter keys and bounds** as the canonical B0:

```text
max_midpoint_spread
max_last_trade_age_seconds
```

Selection rule at each decision time:

1. use midpoint only when an observed two-sided book exists at/before decision time and:
   `ask - bid <= max_midpoint_spread`;
2. recompute spread from best bid/ask; do not trust a source-provided spread field;
3. otherwise use the latest observed last trade whose age is:
   `<= max_last_trade_age_seconds`;
4. if no eligible book/trade exists, B0 is unavailable and the future preregistered missing-data policy applies;
5. `NOT_OBSERVED_IN_SEARCHED_HOURS` is never imputed into a trade;
6. source observability is based on external capture `timestamp_received <= decision_time`.

This rule is explicitly a **third-party reconstruction**, not a claim that the archive itself was publicly readable at decision time.

The archive HTTP `Last-Modified` / `public_available_time` may be later than the decision checkpoint and must not be used to backdate canonical availability.

Forbidden for this external path:
- `SOURCE_KIND_CANONICAL_PIT`;
- `MARKET_PIT`;
- `DatasetSnapshotReference`;
- derived/fabricated `local_first_seen_time`;
- any canonical-PIT claim.
