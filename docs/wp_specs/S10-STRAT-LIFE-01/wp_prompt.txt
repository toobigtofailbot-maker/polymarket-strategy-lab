13. ADAPTATION CLASSIFICATION

Closed vocabulary: ROOT, BOUNDED_ADAPTATION, MATERIAL_ADAPTATION.
Root: required when parent_strategy_version_id is null.
Child baseline: a child must reference an existing exact parent; use the same
strategy_family_id; not be byte/semantic identical to the parent. No-op child versions reject.
Bounded adaptation: a child is BOUNDED_ADAPTATION only if all are true: 1 same family; 2 same
evidence posture; 3 same strategy code identity; 4 identical thesis; 5 identical universe;
6 identical entry_rule; 7 identical exit_rule; 8 identical execution_rule; 9 identical
adaptive-bound declaration; 10 parameter key set is unchanged; 11 every changed parameter is
explicitly adaptive; 12 every changed value falls inside its frozen parent bound; 13 at least
one parameter actually changes. Anything else is MATERIAL_ADAPTATION.
The repository validator derives this classification; caller-provided adaptation_class must
equal the derived value. Do not introduce a deterministic judgment about whether the
adaptation is good. Only mechanical boundedness is classified.

14. RISK-BAND INHERITANCE HELPER
