## 1. Objective

Migrate the existing read-only five-view cockpit (Overview, Market Truth, Experiments, Paper
Operations, Audit / Health) into a maintainable Control Center frontend foundation: typed
same-origin `/api` client, TanStack Query server state with conservative defaults, React Router
declarative URL routing, semantic source-owned primitives and CSS tokens, and deterministic
Storybook/MSW reference states. The 14-route GET-only backend (`src/operator_cockpit.py`) is
byte-unchanged. Control Center is presentation only; it is never trading/risk/strategy/execution
authority.
