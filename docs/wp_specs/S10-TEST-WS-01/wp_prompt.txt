1. TRIGGER / OBJECTIVE
===============================================================================

Trigger evidence: hosted CI run 36437422894 (PR #198, head ec97a25), compat job
windows-2022 / py3.12, failed
tests/data_layer/polymarket/test_market_truth_websocket.py::test_non_store_limit_failed_append_reconnects_not_silently_continues
with `assert 1 >= 2` (only one socket opened). The test slept a fixed 1.4 s and then set stop,
assuming the runner's real first reconnect backoff (_BACKOFF_SCHEDULE[0] == 1 s, awaited via
asyncio.wait_for(stop_event.wait(), timeout=delay)) had completed. On a slow runner stop landed
during RECONNECT_WAIT, the runner returned CALLER_STOP and no second socket opened. It passed
locally and on the other three compat jobs: a timing flake, not a product regression.

The backoff is a module constant and is not injectable through _run_market_websocket.

Objective: remove runner-speed dependence from all four wall-clock-sensitive reconnect tests in
tests/data_layer/polymarket/test_market_truth_websocket.py as one coherent deterministic-test-
synchronization WP, using condition-driven synchronization appropriate to each test:

1. test_reconnect_uses_current_subscription_set_not_original
   - wait for the second connection's reconnect subscription payload to actually be emitted
     (sockets[1].sent non-empty) before stopping; socket creation alone is insufficient because the
     test reads sockets[1].sent[0]. The pre-disconnect fixed sleeps are likewise replaced by waits
     for the first connection's initial payload and for all three dynamic updates being sent.
2. test_normal_book_gaps_are_persisted_and_healed
   - wait deterministically for the durable OPEN TIMESTAMP_REGRESSION gap row before queueing the
     fresh book, then for the HEALED gap evidence itself; no fixed sleep is a success condition.
3. test_continuity_fault_triggers_reconnect_wait
   - bounded asyncio.Event for creation/opening of socket #1 (before feeding frames) and socket #2.
4. test_non_store_limit_failed_append_reconnects_not_silently_continues
   - bounded asyncio.Event for creation/opening of socket #2.

Every wait has a generous finite timeout (30 s) and fails clearly (stop the runner, await it with
the same bound, pytest.fail naming the missing condition) rather than hanging. The real 1-second
product backoff is preserved: this WP removes runner-speed dependence, it does not bypass the
production behavior being tested. Existing assertions are preserved unchanged.
