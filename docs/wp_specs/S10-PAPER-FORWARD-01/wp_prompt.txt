# 4. REQUIRED SEMANTICS
Reuse, do not copy: `build_research_strategy_binding`, `PaperRiskLimits`, `PaperEngine.create_research/open/submit/process_market_event/advance_time`, `PaperStore`, `Wp169ReadOnlyTail`, `build_research_paper_performance_snapshot`, `snapshot_to_mapping`, `run_paper_performance_update`, `load_strategy_lifecycle_store`, native FakeHermesBackend. No second fill, fee, accounting, risk or settlement engine; no new database or market store.
A. Plan freeze: the plan JSON (binding arguments, risk limits, cohort = `allowed_market_ids`, rule `FAIR_VALUE_EDGE_V1` with `min_edge` and `max_quantity`, fee scenario, latency/age limits, outcome handling, optional `strategy_version_id`) is hashed and recorded as the first ledger entry before any decision. `frozen_at_ns` must be earlier than every candidate `source_time_ns` and `decision_time_ns`. That comparison and the first-ledger hash prove only local run order (LOCAL_RUN_ORDER), not historical preregistration or that the plan existed before already-recorded data; prospective/OOS status needs separately authorized, independently witnessed pre-decision plan/capture evidence and is never claimed here. Rerun with different plan bytes fails closed. The binding is always research-only (native flags), `reserved_evidence_policy` NON_CONFIRMATORY_RESEARCH_PAPER, no reserved/OOS refs.
B. Source time: a candidate is admissible only if `source_time_ns < decision_time_ns`. The book used is the native engine's current book for the exact `asset_id` and `market_id` after processing only events with `receive_time_ns < decision_time_ns`; events at or after decision time are processed after the decision. Book age `decision_time_ns - book.receive_time_ns` must be within the binding `max_data_age_ns`; missing, gapped, stale, wrong-market or wrong-asset books give typed NO_TRADE classes, never a fill. Arrival-time fill realism remains native.
C. Rule: holding no position, BUY `max_quantity` iff `fair_value - best_ask - fee_bound(best_ask) >= min_edge`; holding a position in that asset, SELL the held free quantity iff `best_bid - fee_bound(best_bid) - fair_value >= min_edge`; otherwise ABSTAINED_NO_TRADE. All arithmetic Decimal; prices in USDC per share in [0,1]; quantities in shares; time in ns since Unix epoch UTC.
D. Fees: plan fee basis must be `CONSERVATIVE_UPPER_BOUND_ESTIMATE` with a recorded venue `fee_rate`, integer `fee_exponent >= 1`, `maker_rebate_bps == 0` and binding `fee_rate_bps >= fee_rate * 10000` (a proven per-share upper bound of `rate*(p*(1-p))^exponent` for every p in [0,1]), or `SYNTHETIC_TEST_ONLY`. Unknown fee config, exponent 0 or a smaller bps gives COST_UNKNOWN for every candidate; fees are reported as ESTIMATE, never exact venue fees.
E. Funnel and ledger: append-only JSONL, each line hash-chained to the previous and flushed with fsync. Each unique occurrence gets one STARTED before any engine call and exactly one immutable decision-occurrence terminal: ABSTAINED_NO_TRADE, SOURCE_FUTURE, SOURCE_STALE, SOURCE_GAP, WRONG_SCOPE, COST_UNKNOWN, or ATTEMPTED_INTENT. ATTEMPTED_INTENT records the submission outcome only: deterministic native `intent_id` and `order_id`, `risk_permitted` (false when native status is REJECTED) and the initial native status returned by submit; it never records or later rewrites a final order lifecycle. A repeated input row of an already-claimed occurrence gets one DUPLICATE_SUPPRESSED record (its row index and occurrence key) with no STARTED, terminal or native submit. Order lifecycle is derived separately at report/verify time from the verified native PaperStore state at the snapshot cutoff: OPEN and PARTIALLY_FILLED are nonterminal as-of states alongside REJECTED, FILLED, CANCELLED and EXPIRED; NOT_FILLED is an as-of count/quantity observation, never a terminal. Counts reconcile exactly, including after restart: raw_candidate_rows = unique_occurrences + suppressed_duplicate_rows; unique_occurrences = count(STARTED) = count(decision-occurrence terminals), INTERRUPTED_OR_UNKNOWN retained truthfully; ATTEMPTED_INTENT and RECOVERED, each native intent counted once including RISK_DENIED, = native snapshot intent_count; risk_permitted false = native risk_deny_count; per-status as-of counts sum to native order_count and their closed part equals native closed_order_state_counts. Imported candidate JSON is labelled IMPORTED_UNVERIFIED_SIGNAL with its byte SHA-256; no provenance is invented.
F. Restart: rerun on an existing run directory verifies the chain and plan hash, then resumes. A STARTED without terminal is reconciled once: if the native store holds the deterministic intent id it binds that committed intent once as RECOVERED with its native ids and initial status, never resubmitting or double counting it; otherwise INTERRUPTED_OR_UNKNOWN. It never retries under a new identity. A claimed occurrence is never rebooked. A paper store head changed by another writer fails closed (native stale-writer guard).
G. Closure truth: SELL fills and winner-bearing resolutions realize P&L natively. A winner is authentic only from the WP169 hash-bound resolution path; replay-file resolutions are labelled IMPORTED_UNVERIFIED_RESOLUTION. A null winner stays pending. Positions without settlement are UNSETTLED, missing marks keep unrealized UNKNOWN (never 0), and `resolution_pending_count == 0` is never read as all positions closed.
H. Feedback: only with a lifecycle store whose `strategy_version_id` exists and lists the binding `candidate_id` in `evidence_refs`; otherwise FEEDBACK_PENDING_NO_MATCHING_LIFECYCLE with zero backend calls. The backend is a FakeHermesBackend answering with an operator-supplied fixed offline draft; the information cutoff is explicit and must advance. Paper and lifecycle bytes stay unchanged; only the operator-named manager store is written.
I. Report: separate SYNTHETIC_TEST_ONLY, WP169_ACCEPTED_OBSERVATION, IMPORTED_UNVERIFIED_SIGNAL, SIMULATED_PAPER_FILL; realized, unrealized and pending; full funnel counts; research-only and zero-authority flags. No exact venue return, edge, qualification or OOS claim.
